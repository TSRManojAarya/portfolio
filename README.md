# Portfolio — TSR Manoj Aarya

Personal portfolio site for **TSR Manoj Aarya**, Data Analyst & AI/ML Associate.

Dark, typography-led single-page site covering Data Analysis, Machine Learning, NLP, Generative AI and Predictive Analytics work.

## Live

- Production: https://manoj-aarya-portfolio.vercel.app

## Stack

Plain HTML, CSS and vanilla JavaScript in a single self-contained `index.html`. No build step, no dependencies — it can be hosted anywhere static.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
npx serve .
```
